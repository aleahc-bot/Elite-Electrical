=====================================================================
THE FLOATING BUTTON — restyled
=====================================================================
The navy bar is gone. The buttons float on their own over whatever is
behind them, so no slab of colour cuts the page off.

The red pill carries a soft red aura that drifts around it and
breathes, deliberately slow - six seconds a lap - so it reads as alive
without pulling your eye off the page. It stops completely for anyone
whose device is set to reduced motion.

The second button is solid navy now rather than a translucent outline,
because without the bar behind it an outline button would disappear on
a white page.

The gap between the two buttons is click-through, so the bar never
blocks anything underneath it.


=====================================================================
THE SEVEN LEGACY PAGES — brought in line
=====================================================================
These pages were a different generation to the rest of the site: all
their CSS and JavaScript written inline, never loading css/site.css or
js/site.js. That is why they still showed Generators, the old gold
palette and the old logo, and why the floating button never reached
them. Each one now has:

  * the new logo, as a file rather than two base64 images baked into
    the page. That alone takes roughly 100KB off every page.
  * the current palette - gold and the old blues out, the logo's blue
    and silver in
  * the corrected services menu
  * BOOK ONLINE in the header, pointing at the real booking link
    (CONTACT US on Commercial)
  * the floating button

  Each page dropped from ~337KB to ~239KB.
